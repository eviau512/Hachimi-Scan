# 技术规格书 03：书籍曲面展平与遮挡消除功能规格书

> **文档说明**：描述书籍曲面展平与遮挡消除的系统功能边界、输入输出数据形状契约与重采样变换映射。

---

## 1. 3D 曲面展平功能规范 (Curved Page Dewarping Specification)

### 1.1 核心形变原理
书籍中缝处的弯曲导致纸面由平直平面退化为三维空间曲面。系统需要估算从“目标平展图像空间”到“输入弯曲图像空间”的反向坐标位移场（Backward Mapping Grid）。

### 1.2 神经网络接口数据契约 (Neural Interface Contract)
* **输入维度**：`[1, 384, 288, 3]` 或 `[1, 384, 384, 3]`
  * 数据格式：RGB 三通道浮点数，数值归一化至 $[0.0, 1.0]$。
* **输出维度**：`[1, 25, 25, 2]`
  * 语义描述：将平展目标页面划分为 $25 \times 25$ 个离散控制网格节点。输出的每个网格顶点 $(i, j)$ 对应其在原始弯曲图像中归一化的真实采样浮点坐标 $(u, v)$。

### 1.3 纹理重采样规则 (Texture Resampling)
* 在 GPU 或 CPU 端通过双线性插值（Bilinear Interpolation）依据上述 $25 \times 25$ 逆向网格对原始高分辨率图像执行重采样。
* 超出原图归一化区间 $[0.0, 1.0]$ 的边界像素，统一裁切为纯色或透明填充。

## 2. 压纸手指消除功能规范 (Finger Inpainting Specification)

### 2.1 手指检测与分割 (Finger Segmentation)
* **输入图像**：长宽等比缩放至 $320 \times 320$；
* **输出掩码**：单通道概率图 $M(x, y) \in [0.0, 1.0]$；
* **判定门限**：设定置信度阈值 $T_{finger} = 0.90$。高于此阈值的像素判定为手指遮挡区。

### 2.2 纹理修复与合成规则 (Inpainting & Blending)
1. **边缘空白区（Page Margins）**：若手指遮挡点位于页面外侧空白边缘，通过周围正常纸张底色与噪点纹理做向内平滑扩散填充；
2. **正文遮挡区**：调用修复生成网络对遮挡局部进行条件填补；
3. **Alpha 混合准则**：未受手指遮挡的区域（$M(x, y) \le 0.90$）必须 100% 严格透传原始拍摄像素，杜绝任何对真实正文字迹的修改。
