# 技术规格书 06：基于结构直线段检测 (LSD) 的边缘磁吸引擎规范

> **文档说明**：陈述离散几何学公理、图像结构线段检测模型、欧几里得退化三角形不等式吸附公式与手柄交互契约。

---

## 1. 架构核心范式转变 (Paradigm Shift)

针对移动端文档裁剪中“拖拽磁吸容易抽搐抖动”与“调整边缘线时容易误触四角点”的两大核心痛点，本规格书确立两项基础数学准则：

1. **静态直线特征池 vs. 动态逐帧边缘搜索**：
   * 严禁在 60 FPS 触控拖拽事件循环中逐帧执行动态 Canny / Sobel 梯度搜索（手指 1~2px 的微小生理抖动会导致动态梯度极大值在高频跳变，引发视觉抽搐）；
   * 改为在**图片加载进入裁剪界面时，单次执行**基于 LSD（Line Segment Detector）的全局结构线段检测，提取出全图物理直线段特征池（分群为水平线池与垂直线池，并固化图片四外边界）；
   * 触控拖拽时，完全在静态特征池上执行解析几何距离运算，引力场为静态场，从数学根源上消除高频振荡与抽搐。

2. **八点全等欧氏竞争 vs. 角点阶梯式先验优先**：
   * 裁剪框由 8 个控制点组成（4 个角点 + 4 条边的中点）；
   * 手指点按时，8 个手柄处于完全平等的竞争地位，统一依据到手指触控点的欧几里得距离判定归属，杜绝任何“优先判定角点”的偏差。

## 2. 图像结构直线段提取模型 (Structural Line Segment Extraction)

### 2.1 算子选择与性能契约
* 在 C++ Native 端采用 OpenCV 的 `cv::createLineSegmentDetector(cv::LSD_REFINE_STD)` 或类似 LSD 算子。
* **输入**：待裁剪文档的原始 Bitmap。
* **降采样预处理**：若图像最长边大于 $1024\text{ px}$，等比例下采样至最长边为 $1024\text{ px}$ 执行灰度化与 LSD 检测（执行耗时控制在 $10 \sim 15\text{ ms}$ 内），随后将检测出的线段端点坐标等比例映射回原图坐标系。
* **长度过滤**：过滤掉原图尺度下长度小于 $L_{min} = 25\text{ px}$ 的短碎线段。

### 2.2 线段分群与边界固化契约 (Line Bucketing & Boundary Invariants)
将提取出的所有直线段 $S_k = [(x_1, y_1), (x_2, y_2)]$ 按倾角拆分为两个独立集合：
1. **水平直线段集合 (`horizontalLines`)**：
   * 判定准则：$|\Delta x| \ge |\Delta y|$（与水平轴夹角 $\le 45^\circ$）；
   * 存储格式：一维浮点数组 `float[]`，每 4 个浮点数为一组：$[x_1, y_1, x_2, y_2, \dots]$；
   * **固化图片上下外边界**：在数组末尾必须固定追加图片的顶边与底边：
     - 顶边：$[0.0, 0.0, W, 0.0]$
     - 底边：$[0.0, H, W, H]$
2. **垂直直线段集合 (`verticalLines`)**：
   * 判定准则：$|\Delta y| > |\Delta x|$（与水平轴夹角 $> 45^\circ$）；
   * 存储格式：一维浮点数组 `float[]`，每 4 个浮点数为一组：$[x_1, y_1, x_2, y_2, \dots]$；
   * **固化图片左右外边界**：在数组末尾必须固定追加图片的左边与右边：
     - 左边：$[0.0, 0.0, 0.0, H]$
     - 右边：$[W, 0.0, W, H]$

## 3. 八手柄平权欧氏竞争判定协议 (8-Point Equal Proximity Hit Testing)

### 3.1 手柄索引拓扑规范
裁剪框 8 个交互手柄的标准化索引序列定义如下：
* **索引 0**：`TOP_LEFT`（左上角点）
* **索引 1**：`LEFT_CENTER`（左边中点，控制左边）
* **索引 2**：`BOTTOM_LEFT`（左下角点）
* **索引 3**：`BOTTOM_CENTER`（底边中点，控制底边）
* **索引 4**：`BOTTOM_RIGHT`（右下角点）
* **索引 5**：`RIGHT_CENTER`（右边中点，控制右边）
* **索引 6**：`TOP_RIGHT`（右上角点）
* **索引 7**：`TOP_CENTER`（顶边中点，控制顶边）

### 3.2 触控竞争判决法则
* **标准触控热区半径**：$R_{touch} = 34\text{ dp}$。
* 当用户按下屏幕（`ACTION_DOWN`）于屏幕坐标 $(T_x, T_y)$ 时：
  1. 将 8 个手柄的当前坐标映射到屏幕坐标系，记为 $P_i(X_i, Y_i), i \in [0, 7]$；
  2. 计算触控点到所有 8 个手柄的欧氏距离：
     $$d_i = \sqrt{(T_x - X_i)^2 + (T_y - Y_i)^2}, \quad \forall i \in [0, 7]$$
  3. 寻找全局最小距离及其对应索引：
     $$i^* = \arg\min_{i \in [0, 7]} d_i, \quad d_{min} = d_{i^*}$$
  4. 判决归属：
     * 若 $d_{min} \le R_{touch}$，则立即激活该手柄 $i^*$（进入拖拽模式）；
     * 否则，判定为未命中任何手柄（可用于触发全局拖动画布或背景判定）。

> **说明**：此准则彻底消除了误触问题。当用户意图拖动某条边的中点时，由于手指直接点在中点周围，其与中点的距离（如 $10\text{dp}$）远小于到两侧角点的距离（通常 $> 50\text{dp}$），因此绝对精准命中中点手柄。

## 4. 退化三角形不等式磁吸数学模型 (Degenerate Triangle Snapping)

### 4.1 吸附判定公式
当用户拖拽某个边中点时：
* 拖拽左边中点（索引 1）或右边中点（索引 5）：在 `verticalLines` 集合中检索；
* 拖拽顶边中点（索引 7）或底边中点（索引 3）：在 `horizontalLines` 集合中检索。

将当前手指带动的中点坐标映射至原图坐标系，记为待测点 $M(m_x, m_y)$。  
遍历候选集合中每一条线段 $AB$，端点为 $A(x_1, y_1)$ 与 $B(x_2, y_2)$。  
计算点 $M$ 与线段 $AB$ 构成的三角形退化误差 $\epsilon$：
$$\epsilon(M, AB) = \Big| \operatorname{dist}(A, M) + \operatorname{dist}(M, B) - \operatorname{dist}(A, B) \Big|$$
其中 $\operatorname{dist}(P, Q) = \sqrt{(P_x - Q_x)^2 + (P_y - Q_y)^2}$。

* **吸附门限**：$\tau_{snap} = 5.0\text{ px}$（原图像素尺度）。
* **判定准则**：
  若 $\epsilon(M, AB) < \tau_{snap}$，则判定点 $M$ 成功落在直线段 $AB$ 的引力带内，命中该线段 $AB$！  
  若有多条线段满足，选取 $\epsilon$ 最小的那一条作为最优吸附线段。

## 5. 四线拦截无限几何求解 (Four-Line Infinite Interception)

### 5.1 直线替换与交点更新
当拖拽边中点时：
1. **未吸附状态**：该边直线方程平移，两端角点沿相邻两条固定边线滑动截取；
2. **吸附状态**：
   * 命中的线段 $AB$ 确定了一条无限延伸的平面直线 $L_{target}$；
   * 用 $L_{target}$ 直接替换该边当前的无限直线方程；
   * 相邻的两条边线保持绝对静止不动；
   * 通过标准两直线交点公式（SPEC_05 第 1.2 节），分别求出 $L_{target}$ 与相邻两条直线的几何交点，作为该边两端更新后的新角点。

### 5.2 凸多边形有效性校验 (Convexity Verification)
在更新角点坐标后，必须验证 4 个角点构成的四边形是否仍为严格凸四边形：
* 交叉有向面积积（Signed Area Product）必须保持同号：
  $$\operatorname{SignedArea}(P_0, P_1, P_2) \cdot \operatorname{SignedArea}(P_0, P_1, P_3) < 0$$
* 任意对向边中点的间距不得小于屏幕有效宽度的 $2\%$，防止四边形翻转或过度退化。

## 6. 放大镜 (Loupe) 交互协同契约

1. **角点拖拽模式**：
   * 当激活手柄为角点（索引 0, 2, 4, 6）时，悬浮放大镜（Loupe / Magnifier）**保持显示（Visible）**，显示局部放大细节与十字准星，辅助微调角点；
2. **边中点拖拽模式**：
   * 当激活手柄为边中点（索引 1, 3, 5, 7）且**处于吸附锁定状态时**，放大镜**自动隐藏（Invisible / Gone）**；
   * **设计理据**：吸附本身由高精度 LSD 直线提供亚像素对齐，此时边线与文档物理边缘完全重合，放大镜如果在手指附近弹出反而会遮挡用户对整条长边贴合效果的视觉观察。

## 7. 模块实现指引与 JNI 接口契约

### 7.1 Native JNI 接口
在 `NativeEdgeDetector` 中暴露：
```kotlin
// 返回水平直线段池与垂直直线段池 (每4个float表示一条线段 x1, y1, x2, y2)
// 返回 Pair<FloatArray, FloatArray> 或两个独立的 FloatArray
fun detectStructuralLines(bitmap: Bitmap): Pair<FloatArray, FloatArray>
```

### 7.2 C++ 实现规范
* 函数名：`Java_com_scanner_app_engine_NativeEdgeDetector_detectStructuralLines`
* 算子：`cv::createLineSegmentDetector()`
* 输出：水平数组与垂直数组末尾分别补齐 $[0,0,W,0], [0,H,W,H]$ 与 $[0,0,0,H], [W,0,W,H]$。
