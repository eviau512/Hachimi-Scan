# 技术规格书 12：真正过曝饱和嫁接与高光微细节保真规范 (True Saturation Grafting & High-Luma Detail Fidelity Specification)

> **文档性质**：核心算法数学模型与图像质量重构规格书 (Algorithm & Technical Specification)  
> **制定目标**：彻底铲除当前哈基米多帧融合在高亮度区域（室内白墙、门牌文字、白色打印纸等）产生的斑驳色块断层（Posterization）与微细节涂抹糊化，确保暗部、中间调及高亮白色纹理 100% 保持 0EV 基准帧的顶级清晰度与极高信噪比，仅对真正物理过曝饱和的死白高光进行平滑高动态拯救。

---

## 1. 缺陷分析与根本成因 (Forensic Root Cause Analysis)

### 1.1 生硬反光置换导致的色阶撕裂断层 (Hard Specular Glare Replacement)
在 `burst_fusion.cpp` 的 `removeGlare` 逻辑中，存在二值化硬截断判断：
```cpp
bool isSaturated = (b0[0] > 238 && b0[1] > 238 && b0[2] > 238);
if (isSaturated) {
    pDst[x] = bk; // 直接硬替换为 -2EV 帧像素
}
```
- **成因**：238 是一个极其陡峭的硬切点。白色墙体、反光门框在自然光照下往往处于 235~245 波动区间。当相邻像素在 237 和 239 之间跳变时，237 的像素保持基准帧，239 的像素瞬间跳变为 -2EV 帧，导致高亮边缘出现极其刺眼的锯齿状色阶断裂与斑驳色块。
- **治理原则**：**彻底删除该硬截断逻辑**。所有的曝光拓展必须基于连续可导的平滑权重函数。

### 1.2 高光嫁接门限划分过低 ($L_0 > 190$) 侵蚀正常高光细节
- **成因**：在 8 位色彩空间中，$L = 190$ 仅代表约 74.5% 的相对亮度。室内乳胶漆白墙、A4 纸张、门牌标牌等白色主体的正常曝光反射率普遍在 $L \in [195, 235]$。
- 0EV 基准帧在 $L \in [195, 235]$ 时信噪比最高、细节最丰富。而 -2EV 欠曝光帧在该区域由于进光量减少至 1/4，光子散粒噪声急剧升高，且经过透视变换（Homography Warping）双线性插值产生了重采样低通平滑；
- 将 $L \in [195, 235]$ 的健康区域强制与 -2EV 帧融合，直接用低信噪比、被插值平滑的像素覆盖了 0EV 基准帧的清晰纹理，导致门牌文字与白墙严重模糊。

## 2. 核心数学模型重构：真正过曝饱和嫁接 (True Saturation Grafting)

### 2.1 物理饱和判定门限上移至物理过曝区 ($Y_{\text{sat}} \ge 242$)
真实相机的传感器像素饱和仅发生在信号溢出阱容时。定义像素亮度：
$$Y_0(x, y) = 0.299 \cdot R_0 + 0.587 \cdot G_0 + 0.114 \cdot B_0$$

- **绝对基准帧保护区 ($Y_0 < 242$)**：
  $$M(x, y) \equiv 0$$
  涵盖整幅图像中 99% 以上的像素（包括深色阴影、树木建筑、室内白墙、门牌号码、打印文档），**100% 锁死基准帧像素，严禁任何辅助帧像素混合！**

- **过曝平滑过渡区 ($242 \le Y_0 < 252$)**：
  采用三次 Hermite 样条（Smoothstep）保证一阶连续导数：
  $$u = \frac{Y_0 - 242.0}{10.0}$$
  $$M(x, y) = 3u^2 - 2u^3$$

- **完全饱和死白区 ($Y_0 \ge 252$)**：
  $$M(x, y) = 1.0$$

### 2.2 欠曝帧透视对齐插值升级 (Bicubic Interpolation)
将 -2EV 辅助帧的单应性矩阵变换插值模式由 `cv::INTER_LINEAR` 升级为 `cv::INTER_CUBIC`，保留极高频调制传递函数（MTF）：
```cpp
cv::warpPerspective(candFrame, candWarped, H, baseFrame.size(), cv::INTER_CUBIC, cv::BORDER_CONSTANT, cv::Scalar(0, 0, 0));
```

### 2.3 杜绝 Lab 色彩空间双重转换精度损耗
废除 `BGR -> Lab (8位) -> 融合 -> Lab -> BGR` 的有损往返转换流程，直接在 RGB 线性亮度空间进行通道保真自适应混合：
$$C_{\text{final}} = (1 - M) \cdot C_0 + M \cdot \min\left(C_0, \alpha \cdot C_1\right)$$
其中 $\alpha$ 为过渡区光度自适应缩放比，彻底消除 8 位整数 Lab 颜色空间的量化舍入色阶损失。
